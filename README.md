# Gathmo for Claude

The official Gathmo plugin for Claude: plan events, design your own guest page, and collect
guests' photos, videos and voice messages in one Gathmo album.

The plugin lives in [`gathmo/`](gathmo/README.md). Install it in Claude Code with:

```
/plugin install gathmo --marketplace martinfreiwa/gathmo-claude-plugin
```
